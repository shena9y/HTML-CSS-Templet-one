# 🎨 Leon — HTML & CSS Template One

My first HTML & CSS template, built as a training project with **Elzero Web School**. It's a clean, minimal one-page agency template ("Leon — Super Creative & Minimal Agency") featuring a hero landing section, services, portfolio grid, about section and contact area — all hand-coded with pure HTML and CSS.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![Elzero Web School](https://img.shields.io/badge/Training-Elzero_Web_School-blue?style=flat)

🔗 **Live Demo:** [https://shena9y.github.io/HTML-CSS-Templet-one/](https://shena9y.github.io/HTML-CSS-Templet-one/)

## ✨ Features

- 🦸 **Landing hero** with intro text and background imagery
- 🧩 **Services section** with icon-based feature cards
- 🖼️ **Portfolio grid** showcasing project images
- ℹ️ **About section** with descriptive content
- 📬 **Contact section** with social links
- 🍔 **CSS-only dropdown menu** (hamburger icon with hover reveal)
- 📐 **Normalized styles** (`normalize.css`) for cross-browser consistency
- 🔤 Font Awesome icons + Google Fonts (Roboto)

## 🛠️ Tech Stack

- **HTML5** — semantic sections
- **CSS3** — custom styles, Flexbox-based layout
- **Normalize.css** — CSS reset
- **Font Awesome 6** — icons
- **Google Fonts** — Roboto

## 📂 Project Structure

```
HTML-CSS-Templet-one/

├── CSS/

```

## 🚀 Getting Started

**Try it live:** [https://shena9y.github.io/HTML-CSS-Templet-one/](https://shena9y.github.io/HTML-CSS-Templet-one/) — no installation needed!

```bash
git clone https://github.com/shena9y/HTML-CSS-Templet-one.git
cd HTML-CSS-Templet-one
```

Open `index.html` in your browser — no build step, no JavaScript required.
